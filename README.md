# Eri / Portfolio

Terminal-native portfolio built with SvelteKit, TypeScript, and JetBrains Mono.

## Development

```bash
pnpm install
pnpm dev
```

Open `http://localhost:5173`.

## Commands

```bash
pnpm check   # Svelte + TypeScript validation
pnpm build   # production build
pnpm preview # preview production build
```

## Design system

Interface uses GitHub's primary brand palette: neutral-first surfaces with GitHub Green as hero accent. Palette reference: [GitHub Brand Toolkit — Color](https://brand.github.com/foundations/color).

Previous Next.js / React UI and nautical visual system were replaced with responsive terminal shell, boot log, command prompt, status panel, project cards, stack table, and anchor navigation.
